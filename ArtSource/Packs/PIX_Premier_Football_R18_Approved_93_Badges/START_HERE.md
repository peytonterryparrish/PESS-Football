# PIX Premier Football | Approved R18 badge pack

This is the full 93-club asset pack based on the original Tournament Cel Crest edition, not the later 47-crest redesign. The only badge changes are Greyminster FC (Wolves slot C050, W3 Sable Cut) and Spindlehaven FC (Portsmouth slot C017, P4 Harbour Trim). All 91 other badge assets are byte-for-byte the original R18. Club IDs, names, and file names remain stable.

- Native_80: native 80×80 transparent artwork.
- Game_256: transparent 256×256 artwork, integer-scaled with symmetric padding.
- HD_768: transparent 768×768 artwork, integer-scaled with symmetric padding.
- Previews: the full updated roster of crests by division.
- Manifest: all 93 club IDs and paths, plus the selection used.

Use the same club IDs to match existing roster and stadium data. No game integration is included.
